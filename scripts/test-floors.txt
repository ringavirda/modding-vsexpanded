# Minimum test count per suite - the discovery floor.
#
# WHY THIS EXISTS. A test assembly that fails to LOAD does not report a failure. xUnit resolves the
# types of a test class during discovery, before the module initializer registers VsAssemblyResolver,
# so a single static field whose type is a value type instantiated over a game type (a
# `ValueTuple` of `Vec3i`, say) makes the whole assembly skip with:
#
#     [xUnit.net] Skipping: SteelmakingExpanded.Tests (could not find dependent assembly 'VintagestoryAPI...')
#     No test is available in ... SteelmakingExpanded.Tests.dll
#
# `dotnet test` then exits 0 and prints NO `Passed!`/`Failed!` summary at all, so a runner that only
# reads the exit code - or greps for `Passed!|Failed!|error` - reports the run as passing with a
# blank result line. Every test in that suite can disappear and every lane says PASS. That is not
# hypothetical: it happened to this repo's smex suite (217 tests) and was caught by eye.
#
# So both runners parse the `Total:` the summary carries and check it against the floor below. A
# missing summary is a hard failure in its own right, because that is the shape the load failure has.
#
# HOW TO SET A FLOOR. A floor, never an exact count - adding tests must never break the run. Set it
# a few percent under the current count (~95%), the same ratchet convention scripts/coverage_gate.py
# uses: low enough not to flap on a refactor that consolidates a few cases, high enough that losing a
# test CLASS is caught rather than only losing the whole assembly. Raise them as suites grow.
#
# ⚠ Deliberately deleting tests below a floor is meant to make the run fail. Lower the floor in the
# same change, so the deletion is recorded here rather than absorbed silently.
#
# Read by BOTH scripts/run-tests.ps1 and scripts/run-tests.sh - it is the one place these numbers
# live, so the two runners cannot drift apart. A project with no row here is a hard error in both,
# so adding a test project means adding a row.
#
#   <test project name> = <minimum tests the suite must discover>
