#### Piston stroke sounds fire ~20x/second on a backward-running cycle and exhaust the game's sound cap

- **where** `src/IronIndustryExpanded/BlockStructures/Engine/PistonCycleSounds.cs:78-84` · portability: clean · area: ppex-machines
- **bug** `PistonCycleSounds.Crossed` reads any `cur < last` as "the clip wrapped past the end" and returns true if the threshold is anywhere after `last` or up to `cur`. A cycle whose frame legitimately decreases — an MP shaft turning the other way, or a sub-machine phase-lock that writes `CurrentFrame` directly and can jump back — arrives identically, so both keyframes fired on nearly every 50 ms tick instead of twice a revolution. A handful of machines then exhaust VS's concurrent-sound cap, at which point all audio (including the game's own) starts being dropped.
- **do** Replace the body of the private `Crossed(float last, float cur, int totalFrames, float threshold)` in src/IronIndustryExpanded/BlockStructures/Engine/PistonCycleSounds.cs with the forward-delta form:

    if (totalFrames <= 1) return false;
    float delta = cur - last;
    if (delta < 0f) delta += totalFrames;
    if (delta <= 0f || delta > totalFrames / 2f) return false;
    float offset = threshold - last;
    if (offset < 0f) offset += totalFrames;
    return offset > 0f && offset <= delta;

Keep the public Fire / CrossedUpStroke / CrossedFrame signatures unchanged — they all route through this one private method, so the air blower, the engine strokes and the steam puff are all covered by the single edit.
- **risk** Two behavioural narrowings to be aware of. (a) `delta > totalFrames / 2` now suppresses sounds when the frame jumps more than half a loop in one tick — a legitimately very fast animation (>10 revolutions/second at the 50 ms client tick) would go silent instead of firing. (b) A genuinely reversed engine now plays no stroke sounds at all rather than a storm; that is the intended trade but it is a behaviour change, not just a rate limit. Any test asserting the old wrap predicate (search test/IronIndustryExpanded.Tests for PistonCycleSounds) will need updating.

#### MoltenRenderer rebuilds its texture AssetLocation from scratch on every render frame
